# „Meistrite aabits” Hooandjas

Kati Murutari kaheköitelise aabitsa ühisrahastuskampaania. Eesmärk 7 000 €, kampaania 6. jaanuar – 21. veebruar 2027.

## Failid
- `KAMPAANIA.md` – kogu kampaaniapakett: eelarve, toetuspaketid, kampaanialehe tekst, kommunikatsioonistrateegia, kalender, mõõdikud ja riskid
- `Meistrite_aabits_Hooandja_kampaania.pdf` – sama pakett PDF-ina
- `Meistrite_aabits_Hooandja_kampaania.docx` – muudetav Wordi versioon
- `maandumisleht.html` – kampaania maandumisleht (avaneb brauseris)

## Enne käivitamist
1. Margot kinnitab käibemaksu raamatuga toetustelt (vajadusel eesmärk 7 500 €).
2. Kati kinnitab 500 € veebitunni paketi.
3. Hooandjalt: projekti ülevaatuse aeg ja raha laekumise aeg.
4. Maandumislehele päris Hooandja link.
